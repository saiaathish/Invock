# Current State Audit

## Executive verdict

Invock is a working TypeScript MCP reference monitor with a substantially tested local boundary: stdio mediation, Streamable HTTP POST plus optional GET/SSE, shared invocation authorization, schema validation, session-scoped taint fingerprints, approvals, persistent drift quarantine, SQLite receipts, a loopback API, an authenticated SDK authorization route, identity/evidence binding, and tested authority primitives are implemented. The current verified baseline is green: 322 tests passed with zero failures or skips, and the build passed.

The repository is **NOT READY** for the transformation mandate's final READY condition. The current local boundary is materially broader than the initial baseline: signed workload identity, human capsule activation, authority bindings, expanded lineage transforms, local control-plane/evidence surfaces, judge mode, an executable 18-scenario Arena, property/fuzz/chaos suites, digest-pinned product Docker containment, receipt-key history, startup SQLite integrity checks, resolved lockfile inventory, and signed local supply-chain evidence are implemented and locally tested. Two bounded isolated release rehearsals passed with separate project copies, stores, runtime identities, receipt databases, ephemeral ports, and cleanup, but clean-install and externally attributable release proof remain unproven. Five current independent audit reports are present, yet the audit gate is not all-PASS: containment retains scoped P1 findings, supply-chain retains the external-provenance release gate, and the product report retains P2 claim-hygiene concerns. Broad WCAG/assistive-technology accessibility, external CI/registry provenance/advisory binding, and production deployment remain unproven. Existing certification banners prove the commands they actually execute, not every label printed in those banners.

> **Current verification update (2026-08-02):** `pnpm test` passed 322/322; `pnpm typecheck`, `pnpm lint`, and `pnpm build` passed; the direct upstream protocol regression and accessibility child-environment regression passed; the scoped Chromium accessibility runner, protocol suite, judge safe/blocked path, local containment, and digest-pinned Docker probes passed. The five current independent reports below are evidence boundaries, not release proof; external provenance, downloaded artifact/SBOM verification, GitHub attestation verification, GHCR digest verification, and production deployment remain open until the exact clean release commit is published and checked. Older matrix entries below retain earlier audit evidence and must be read as historical wherever they conflict with this update.
