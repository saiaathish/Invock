# Support boundary

Invock is currently a local-first reference implementation. Support questions should include the exact revision, Node/pnpm versions, command, redacted output, and whether Docker or macOS sandboxing was available.

Do not include bearer tokens, private keys, real credentials, raw agent arguments, or private repository contents in reports. Reproduce with fake data and loopback fixtures.

Hosted service SLAs, enterprise support, security response times, and production operational guarantees are not offered by this repository.
