# Roadmap

## Next release gates

- Complete eighteen-group Arena scenarios with real protected, basic-static, and unprotected paths.
- Run two isolated clean-install release rehearsals and five fresh read-only audits.
- Expand the passing scoped browser accessibility/responsive checks into full WCAG and assistive-technology coverage.
- Add bounded property, fuzz, chaos, and meaningful mutation suites.
- Prove Docker and macOS containment on the target release environments.

## Product expansion

- Persist and distribute signed policy bundles across projects.
- Bind verified workload identity and project/session state into every adapter path.
- Add supply-chain/SBOM/provenance evidence and an explicit dependency review workflow.
- Design hosted control-plane, SSO/SCIM, RBAC, SIEM, and remote evidence interfaces without claiming implementation early.

## Non-goals

No roadmap item authorizes claims of absolute security, hardware attestation, universal semantic exfiltration detection, or production readiness without direct evidence.
